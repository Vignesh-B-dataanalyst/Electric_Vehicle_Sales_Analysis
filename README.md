# ⚡ EV Sales Analysis Dashboard

This Power BI project analyzes electric vehicle (EV) sales across different states and time periods.  
It includes key insights on top-performing vehicle types, year-wise trends, and sales distribution by region.

### 🔍 Highlights:
- State-wise and year-wise EV sales trends
- Top vehicle categories and classes
- Interactive maps and filters
- Forecasting future sales using historical data
